# vehicles-web-app
#aplicación web para análisis de datos de vehículos
#La aplicación web permite visualizar la estadistica de los vehiculos listados, donde se puede observar la relación de los kilometros recorridos. O tambipén se puede visualizar la relación entre el precio del vehiculo versus los kilometros recorridos
#En la aplicación web se muestran 2 botones, al presionar creación de histograma se visualizaran los km recorridos. Al presionar el otro botón, el diagrama de dispersión se puede observar la comparativa de que a mayor kilometraje menor precio o viceversa.
